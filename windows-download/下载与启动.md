# 下载与启动 Windows 版

适用 Windows 10 / 11 x64，无需安装 Node.js，也不需要发布 GitHub Release。

1. 在仓库首页点击绿色 **Code → Download ZIP**，下载整个仓库。
2. 将下载的仓库 ZIP **完整解压**。不要直接在压缩包窗口里运行脚本。
3. 进入解压后的 `windows-download` 文件夹。
4. 双击 **start-windows.cmd**，等待合并、SHA-256 校验、解压和启动。
5. 首次操作完成后，软件在同目录新建的 `RAYSPACE-1.0.0-时间戳` 文件夹内；以后直接运行其中的 **RAYSPACE Scoreboard.exe**。

四个 `.part01`～`.part04` 文件共同组成同一个已校验的 Windows 安装包，不要改名或遗漏。脚本调用 Windows 自带的 PowerShell 校验并解压，不修改执行策略，不要求管理员权限，不从网络下载其他程序。

程序的实际安装包 SHA-256 和分片校验值见 `manifest.json`。此版本未做 Windows 代码签名。

OBS 添加浏览器来源时，在软件里点击「复制 OBS 地址」，来源尺寸设为 1920×1080。建议铁拳8使用无边框窗口模式。完整功能和验证范围见仓库根目录 README.md。
