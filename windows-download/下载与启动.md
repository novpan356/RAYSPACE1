# Windows 安装版

**不需要 CMD，不需要合并分片，也不需要 Node.js。**

1. 点击 [下载 RAYSPACE-Scoreboard-Setup-1.0.1.exe](https://github.com/novpan356/RAYSPACE1/raw/refs/heads/main/windows-download/RAYSPACE-Scoreboard-Setup-1.0.1.exe)。
2. 双击下载的 EXE，按照安装向导选择安装位置并完成安装。
3. 以后从桌面或开始菜单的 **RAYSPACE 铁拳8记分板** 快捷方式启动。

也可用仓库的 Code → Download ZIP，解压后直接运行本目录的同名 EXE。

适用 Windows 10/11 x64，安装到当前用户目录，不要求管理员权限。可从 Windows 设置 → 应用中卸载，默认保留选手及样式配置。安装包约 98MiB，不包含在线安装阶段，不从网络下载运行组件。

软件使用方法及 OBS 接入见根目录 README.md。此安装包未做 Windows 代码签名，真机安装及游戏兼容性尚未实测；构建内容已通过 CRC 和 SHA-256 校验。校验值见同目录 SHA256SUMS.txt。
