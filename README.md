# RAYSPACE · 铁拳8 比赛记分板

**直接下载 Windows 软件：** [下载整个仓库 ZIP](https://github.com/novpan356/RAYSPACE1/archive/refs/heads/main.zip)，完整解压后进入 `windows-download`，双击 `start-windows.cmd`。脚本会合并分片、验证 SHA-256、解压并启动软件。无需 Node.js。详见 [下载与启动](windows-download/下载与启动.md)。

Windows 10/11 x64 桌面软件。采用确认的黑红切角模板，原生 1920×1080 透明画布，游戏画面不缩放。无需登录、无需联网运行、不向游戏进程注入代码。

## 使用 Windows 版

1. 下载 `RAYSPACE-Scoreboard-1.0.0-Windows-x64.zip`，**将整个 ZIP 解压**到一个文件夹。
2. 双击 `RAYSPACE Scoreboard.exe`。不要只移动 EXE；同目录运行时文件必须一起保留。
3. 在控制台填写双方 ID、身份、比分，点击「替换图标」选择本地 PNG / JPEG / WebP。每张图最大 1 MB，建议正方形透明 PNG。
4. 修改自动保存。左右互换包含姓名、身份、图标与比分。比分范围 0～999，归零与信息修改可撤销（最多 50 次，本次运行内）。
5. 控制窗口关闭后留在系统托盘；从托盘双击可重新打开。要结束服务和快捷键，请用托盘「退出」或控制台「退出软件」。

首个版本未做 Windows 代码签名。请按你自己的设备安全策略运行；无需管理员权限。软件只监听 `127.0.0.1:17880`，不开放局域网访问。

## 两种显示方法

**OBS 浏览器源（推荐直播）：**

- 点击「复制 OBS 地址」。OBS → 添加来源 → 浏览器，粘贴地址。
- 宽 **1920**，高 **1080**，保留 OBS 默认透明背景 CSS，缩放 100%，与 1080p 游戏源对齐。
- 将浏览器源放在游戏源上方。不要改变游戏源比例、不要给游戏加边栏。
- 默认地址 `http://127.0.0.1:17880/overlay.html`。OBS 和软件必须运行在同一台电脑；软件退出后来源断开。

**桌面透明显示层：**

- 在「显示与样式」中选择游戏显示器，点击「开启桌面计分条」。
- 显示层无边框、置顶、不抢焦点，启用鼠标穿透。仅覆盖屏幕顶部必要区域。
- 建议使用**无边框窗口**游戏模式。Windows 独占全屏可能覆盖桌面窗口，这时使用 OBS 浏览器源。
- 桌面显示层要求显示器为 16:9；非 16:9 的桌面请使用 OBS 的 1920×1080 浏览器源，避免定位错误。
- 屏幕采集会同时采集桌面显示层。如果已用浏览器源，请关闭桌面显示层，避免重复叠加。

位置以本项目参考图的默认 HUD 布局校准：左右条底边 y=70；计时器、六盏胜局灯和 y≥70 的游戏区域没有不透明覆盖。角色头像原始位置、HUD 缩放或游戏版本变化时，须在预览/OBS 中重新核对；软件不读取游戏内状态，不会自动识别不同 HUD 布局。16:9 的 1440p/4K 桌面显示层会随屏幕宽度等比映射，OBS 输出始终按 1080p 设置。

## 默认快捷键

| 操作 | 默认按键 |
| --- | --- |
| 左侧 +1 / −1 | Ctrl + Alt + 1 / 2 |
| 右侧 +1 / −1 | Ctrl + Alt + 3 / 4 |
| 左右全部信息互换 | Ctrl + Alt + S |
| 撤销 | Ctrl + Alt + Z |
| 显示 / 隐藏记分条（桌面和 OBS 同步） | Ctrl + Alt + H |

这些是键盘上方数字键，不是小键盘键。桌面版在控制台不处于前台时也可使用。快捷键可在设置中修改，例如 `Control+Shift+F1`；注册冲突会提示并尽量恢复旧绑定，不会抢占其他软件的已注册快捷键。可临时关闭「启用全局快捷键」。若游戏以管理员权限运行而快捷键不响应，优先改为普通权限游戏/OBS，或使用控制台按钮。

## 可自定义内容

- 双方 ID、身份小标题、比分、两端图标、赛事/轮次标题（留空隐藏）。
- 主色、姓名颜色、身份颜色、底板颜色、整体不透明度。
- 快捷键与游戏显示器。
- 长文字会压缩至固定文字区域，不允许伸入计分灯。中文使用系统字库，英文姓名使用随包字体。
- 为保护固定 HUD 避让区域，不开放任意拖动、纵向位移和板块几何尺寸编辑。

配置写入 Windows 用户数据目录（通常为 `%APPDATA%/rayspace-tekken-scoreboard/scoreboard.json`，实际路径以 Electron `app.getPath('userData')` 为准）。可使用「导出配置」备份，导入会校验比分、颜色、快捷键和图标格式。损坏配置会备份为同目录的 `.bak` 文件，再回退默认值；之后保存仍可正常恢复。退出后记住所有设置；桌面透明窗口每次启动需主动开启，防止误覆盖屏幕。

## 开发

Node.js 22 或更新版本：

```sh
npm ci
npm run setup:electron
npm start
```

如依赖安装默认执行了 Electron 安装钩子，`setup:electron` 会复用已下载运行时。纯浏览器开发：`npm run dev`，在终端显示的本地地址打开控制台；此模式没有原生置顶与全局快捷键。

```sh
npm test
npm run pack:win
```

Windows ZIP 生成到 `release/`。跨平台构建的 ZIP 未签名；仅使用 Electron 官方预编译运行时，打包不改写可执行文件签名。`test/ui-smoke.py` 需 Python、Playwright、Pillow 及 Chromium，针对运行中的 `npm run dev` 执行真实浏览器操作和透明像素避让验证。

## 验证范围

核心状态/HTTP 测试验证计分边界、互换、撤销、持久化、图标格式、跨站请求和快捷键配置失败回滚。浏览器测试验证编辑、替换图标、加分、互换、撤销、可见性、OBS 实时同步、长文字边界及透明像素。

Electron 已在 Linux 虚拟桌面实际验证置顶、不抢焦点、鼠标点击穿透、全局快捷键（其他原生窗口在前台时）与关闭控制台后驻留。Windows 包在 Linux 云环境构建。此处无法直接运行 Windows 或真实铁拳8/OBS，因此不能声称已完成 Windows 游戏内兼容性测试；请在实际机器上检查所用 HUD 和快捷键是否适配。
